## Description
A simple paper plugin for ScreamingSandals' BedWars that adds a GUI for arena selection.

## Commands
- `/bwgui reload` - Reloads the configuration file.
- `/bwgui help` - Displays help information about the plugin commands.
- `/bwgui version` - Displays the current version of the BedWarsGUI plugin.
- `/bwgui` - Opens the BedWars arena selection GUI.

## Dependencies

To ensure the plugin functions correctly, your server must have the following plugins installed:

* **[ScreamingSandals' BedWars](https://www.spigotmc.org/resources/screaming-bedwars-1-8-8-1-21-10.63714/)** or my [fork](https://github.com/TavstalDev/BedWars): Required for BedWars compatibility.
